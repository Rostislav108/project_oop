# Проект: модель интернет-магазина (ООП)

Учебный проект по основам ООП на Python: классы `Product` и `Category`
с приватными атрибутами, геттерами и сеттерами, а также загрузка
данных о товарах из JSON-файла.

## Структура проекта

```
src/
├── __init__.py
├── products.py     # класс Product
├── categories.py   # класс Category
└── file_loader.py  # загрузка категорий и товаров из JSON
data/
└── products.json   # данные о категориях и товарах
tests/
├── __init__.py
├── test_products.py
├── test_categories.py
└── test_file_loader.py
htmlcov/            # отчёт о покрытии тестами
```

## Установка

```bash
pip install -r requirements.txt
```

## Классы

### Product (`src/products.py`)

Класс товара интернет-магазина:

- `name` — название товара;
- `description` — описание товара;
- `quantity` — количество товара в наличии (`int`);
- `__price` — **приватный** атрибут цены (`float`).

Реализовано:

- `@property price` — геттер цены;
- `@price.setter price` — сеттер цены: если новая цена меньше или равна
  нулю, выводится сообщение «Цена не должна быть нулевая или
  отрицательная», а значение не присваивается;
- `@classmethod new_product(product_data)` — создаёт объект `Product`
  из словаря с параметрами товара.

### Category (`src/categories.py`)

Класс категории товаров:

- `name` — название категории;
- `description` — описание категории;
- `__products` — **приватный** список товаров категории.

Реализовано:

- `add_product(product)` — добавляет товар в приватный список
  (через `append`) и увеличивает счётчик товаров на 1; ничего не возвращает;
- `@property products` — геттер, возвращает строку со всеми товарами
  по шаблону «Название продукта, X руб. Остаток: X шт.».

У класса есть два **атрибута класса**:

- `category_count` — общее количество созданных категорий;
- `product_count` — общее количество товаров во всех категориях.

Атрибуты класса заполняются автоматически при создании нового объекта
и доступны у каждого объекта категории.

### Загрузка из JSON (дополнительное задание)

Функция `load_categories_from_json` (`src/file_loader.py`) читает файл
`data/products.json` и создаёт объекты классов `Category` и `Product`.

## Магические методы

- `Product.__str__` — строковое представление товара:
  «Название продукта, X руб. Остаток: X шт.»;
- `Product.__add__` — сложение двух товаров даёт полную стоимость
  товаров на складе (цена × количество каждого товара);
- `Category.__str__` — строковое представление категории:
  «Название категории, количество продуктов: X шт.», где количество —
  общее число всех товаров на складе категории;
- `CategoryIterator` — вспомогательный класс для перебора товаров
  категории в цикле `for` (дополнительное задание).

## Тестирование

Проект покрыт автоматическими тестами на **pytest**. Тесты проверяют:

- корректность инициализации объектов класса `Product`;
- работу геттера и сеттера цены (проверку положительного значения);
- класс-метод `new_product`;
- корректность инициализации объектов класса `Category`;
- работу `add_product` и геттера `products`;
- строковое представление товара и категории, сложение товаров;
- перебор товаров категории (итератор);
- подсчёт количества продуктов и категорий;
- загрузку категорий и товаров из JSON.

Запуск тестов:

```bash
pytest
```

Покрытие кода тестами (требуется более 75 %):

```bash
pytest --cov=src --cov-report=term-missing
```

Отчёт о покрытии в HTML сохранён в папку `htmlcov`:

```bash
pytest --cov=src --cov-report=html
```
